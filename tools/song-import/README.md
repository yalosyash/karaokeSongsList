# Добавление песен

Утилита работает с каталогом этого проекта. Откройте `add-song.cmd` двойным кликом и вставьте ссылку YouTube, затем проверьте предложенные сведения и текст.

Нужны Node.js, установленные в корне проекта зависимости (`npm ci`) и Chrome. Для тестового Chrome выполните в корне `npm run test:browser`.

Из корня проекта можно запустить:

```sh
npm run add-song -- "https://www.youtube.com/watch?v=VIDEO_ID"
```

Утилита получает название видео, предлагает исполнителя, название, язык, раздел и жанр. Затем загружает текст, проверяет встраивание и пересобирает `data/catalog.js`. Запрещённое к встраиванию видео будет открываться на YouTube.

Если загрузка или проверка прервалась, локальные данные сохраняются. Для продолжения используйте ту же ссылку с `--resume`:

```sh
node tools/song-import/add-song.js --resume "https://www.youtube.com/watch?v=VIDEO_ID"
```

После исправления текста вручную также продолжите через `--resume`. Утилита выводит точную команду при ошибке.

## Файлы

- `add-song.cmd` — запуск в Windows.
- `add-song.js` — диалог и добавление песни.
- `song-import.js` — разбор ссылки и названия ролика.
- `tests/` — проверки утилиты.

Общие скрипты `scripts/fetch-lyrics.js`, `scripts/check-embeds.js` и `scripts/build-catalog.js` используются совместно с проектом; отдельной установки зависимостей для утилиты нет.
