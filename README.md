# 🎤 Караоке для стрима

[![Tests](https://github.com/yalosyash/karaokeSongsList/actions/workflows/tests.yml/badge.svg?branch=main&event=push)](https://github.com/yalosyash/karaokeSongsList/actions/workflows/tests.yml)

Одностраничный сайт для караоке: весь список песен, плеер и первые слова — на одном экране, без переключения вкладок.

Слева список песен с поиском и фильтрами, справа — плеер и первые слова выбранной песни. Клик по песне только выбирает её, запуск — кнопкой ▶, клавишей `Enter` или двойным кликом.

## Как добавить новую песню

Добавление песни завершено только после выполнения и проверки **всех шагов ниже**, включая тексты, встраивание видео и проверку интерфейса. Это относится и к добавлению песен из `notes/source-links.md`. Не пропускайте шаги молча: если что-то не удалось, укажите конкретную песню и причину в отчёте о результате.

Нужна ссылка на YouTube. Id видео — это 11 символов из `watch?v=…`:

```
https://www.youtube.com/watch?v=tOGTcsley1U

"tOGTcsley1U" - это id
```

**1. Добавьте запись** в конец `content/songs.json`:

```json
{
  "id": "tOGTcsley1U",
  "artist": "Adele",
  "title": "Skyfall",
  "genre": "Соул",
  "category": "Зарубежная музыка",
  "lang": "en"
}
```

Все поля обязательны:

- `genre` — свободный текст, новый жанр сам появится в фильтре;
- `lang` — только `ru` или `en`;
- `category` — строго из списка: «Русская поп-музыка», «Русский рок», «Зарубежная музыка», «Детские и мультфильмы», «Саундтреки и мюзиклы», «Советская эстрада и кино», «Военные и народные» — иначе песня не попадёт ни в один чип.

Если у песни есть второй вариант караоке, добавьте его массивом — появится кнопка версий:

```json
  "alt": ["UadrtR56n6s"]
```

**2. Добавьте сведения о видео** в `content/meta.json`: `id`, исходное название ролика в `title` и название YouTube-канала в `author`. Проверьте исполнителя и название по самому видео. Для альтернативных версий тоже добавьте сведения; существующую песню не дублируйте, используйте `alt`.

**3. Загрузите и проверьте текстовые подсказки.** Для новых песен запустите загрузку по их основным `id` (для альтернативной версии используйте основной `id` существующей песни, если у неё ещё нет текста):

```bash
node scripts/fetch-lyrics.js --only id1,id2
```

Проверьте в `content/lyrics.json`, что у каждой добавленной песни есть непустой `verse`, текст соответствует песне, а куплет и припев не содержат служебных строк и лишних повторов. Если загрузчик не нашёл текст, найдите и добавьте подсказку вручную. Если получить текст не удалось, явно сообщите об этом: такой пункт остаётся незавершённым. Формат ручной записи:

```json
  "tOGTcsley1U": {
    "verse": ["This is the end", "Hold your breath and count to ten"],
    "chorus": ["Let the sky fall"]
  }
```

**4. Проверьте встраивание всех добавленных видео**, включая `alt`. Сначала пересоберите каталог и запустите локальный сервер:

```bash
npm run build
npm start
```

При работающем сервере в другом терминале выполните:

```bash
node scripts/check-embeds.js --only id1,id2
```

Проверьте результаты для каждого нового видео в `content/embeds.json`. Тайм-аут или ошибка сети не подтверждают запрет встраивания — выясните причину и повторите проверку. Если автор запретил встраивание, проверьте открытие ролика на YouTube и сообщите об ограничении.

**5. Пересоберите итоговый каталог и проверьте интерфейс:**

```bash
npm run build
npm test
```

В локальном сайте проверьте каждую добавленную песню: она находится поиском, отображает правильные сведения и текстовые подсказки, запускает нужное видео. Для альтернативных версий проверьте переключение; для запрещённых к встраиванию видео — открытие на YouTube. Успешная сборка или общий тест сами по себе не подтверждают эти проверки для новых песен.

**Перед завершением сверьте результат:** все исходные ссылки учтены, сведения о видео заполнены, тексты проверены, встраивание проверено, итоговый каталог пересобран, тесты прошли, новые песни проверены в интерфейсе. В отчёте перечислите добавленные песни и версии, выполненные проверки и оставшиеся проблемы. Не называйте добавление полностью завершённым, пока есть невыполненные пункты.

## Служебные команды

Пользовательские сценарии и границы автоматической проверки: [tests/README.md](tests/README.md).

```bash
npm start                                         # локально: http://localhost:4173
npm run test:browser                              # установить тестовый Chrome после npm ci
npm test                                          # проверка интерфейса
npm run test:mutations                            # убедиться, что тесты ловят намеренные поломки
npm run fetch-lyrics                              # дозагрузить тексты из LRCLIB
npm run check-embeds                              # проверить, встраиваются ли видео
node scripts/check-embeds.js --only id1,id2         # проверить выбранные видео
```

Без параметров `fetch-lyrics` трогает только песни без куплета; с `--only` повторно загружает тексты указанных песен, поэтому не включайте в список уже проверенные вручную подсказки. `check-embeds` работает при запущенном `npm start` и помечает видео, где автор запретил встраивание: такие открываются на YouTube, после проверки нужен `npm run build`.
