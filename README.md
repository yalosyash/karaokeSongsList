# 🎤 Караоке для стрима

Одностраничное приложение для стримерши, которая поёт: весь список песен, плеер и первые слова — на одном экране, без переключения вкладок.

## Как запустить

```bash
npm install      # один раз
npm start        # http://localhost:4173
```

Сайт статический — папку можно выложить на любой хостинг (GitHub Pages, Netlify, Vercel) без сборки.
Сборщика нет: браузер загружает ES-модули напрямую, поэтому нужен любой статический сервер.
Открыть `index.html` двойным кликом (`file://`) не получится — браузер блокирует модули по CORS.

## Как это работает

**Слева — список песен.** Сверху мелким шрифтом исполнитель, снизу крупно название. Ниже — бейджи категории и жанра (появляются при наведении).

**Клик по песне — только выбор.** Видео не запускается: справа видно название, теги и первые слова, можно спокойно повыбирать другие песни. Караоке стартует, когда вы этого захотите — кнопкой ▶, клавишей `Enter` или двойным кликом по песне. Повторный клик по играющей песне — пауза.

**Справа — первые слова.** Первый куплет и припев, чтобы вспомнить мотив, если забыла, что это за песня. Кнопка `F` разворачивает текст на весь экран — удобно, когда нужен крупный шрифт.

## Возможности

| Что             | Как                                                                                                        |
| --------------- | ---------------------------------------------------------------------------------------------------------- |
| Поиск           | поле сверху или клавиша `/`. Ищет по песне, исполнителю, жанру и категории. Понимает `максим` → `МакSим`   |
| Фильтры         | чипы категорий (Поп, Рок, Зарубежное, Детское, …), отдельно жанр и язык                                    |
| Сортировка      | по исполнителю, названию, категории, жанру — с группировкой по буквам/разделам                             |
| Избранное       | ★ в строке песни или кнопка `S`. Чип «★ Избранное» показывает только свой сет-лист. Сохраняется в браузере |
| Случайная песня | кнопка «Случайно» или `R` — для «а что мне сейчас спеть» (песня только выбирается, видео не запускает)     |
| Размер текста   | кнопки `A−` / `A+`, запоминается                                                                           |
| Две версии      | если у песни два караоке-видео, кнопка «Версия 1/2» переключает их; версия, запрещённая для встраивания, открывается на YouTube |
| Офлайн          | список и тексты кешируются — сайт открывается мгновенно даже без интернета (видео всё равно из сети)       |

## Видео, которые нельзя встроить

У 23 песен автор видео запретил встраивание на сторонних сайтах (ошибка YouTube 150). Это не сбой сайта: такое видео не проиграется ни в каком встроенном плеере.

Такие песни помечены в списке значком `↗`, а на месте плеера показывается сообщение и кнопка **«Смотреть на YouTube»** — вместо чёрного прямоугольника с ошибкой. Ссылки при этом остались ровно те, что были в исходном списке.

Перепроверить статус всех видео (~10 минут, нужен Chrome и запущенный `npm start`):

```bash
npm run check-embeds    # → content/embeds.json
npm run build           # → data/catalog.js с пометками
```

Если Chrome установлен не в стандартный путь, укажите его в `CHROME_PATH`.

## Горячие клавиши

```
/        поиск
↑ ↓      выбор песни (без запуска видео, из поиска тоже работает)
Enter    петь
Space    пауза / продолжить
S        в избранное
F        текст во весь экран
R        случайная песня
Y        открыть на YouTube
0        с начала
Esc      стоп / закрыть текст
```

## Обновить каталог

Песни лежат в `content/songs.json`, тексты — в `content/lyrics.json`. После правок:

```bash
npm run build    # перегенерирует data/catalog.js
npm test         # проверяет, что ничего не сломалось
```

Не хватает текста у новой песни — `npm run fetch-lyrics` дозагрузит только те, где куплета нет. Сборка и загрузка проверяют результат одинаковой чисткой (`scripts/lib/lyrics.js`), поэтому ручные правки в `lyrics.json` не теряются.

Тексты — реальные, из открытой базы [LRCLIB](https://lrclib.net). У 168 из 170 песен есть куплет (у 146 — ещё и припев).
