# Проверки пользовательских сценариев

Запуск: `npm ci`, затем `npm test`. Нужен установленный Google Chrome;
путь можно задать переменной `CHROME_PATH`. Тест сам запускает локальный сервер
на порту 4287 и закрывает его после прогона. Не запускайте два прогона одновременно.
Используется Puppeteer Core, без Jest, Vitest и Playwright.

В GitHub Actions набор запускается при каждом push, в pull request и вручную
через Actions → Tests → Run workflow. Workflow `tests.yml` устанавливает
зависимости через `npm ci`, собирает каталог и выполняет `npm test` на Windows
с Chrome и Node.js 22. Бейдж в корневом README показывает результат push в `main`;
по нажатию открываются прогоны с журналами проверок. До первого прогона статуса нет.

## Карта покрытия

| Пользовательский сценарий | Автоматическая проверка |
| --- | --- |
| Первый запуск | Каталог, отсутствие выбора, отключённые кнопки плеера |
| Найти песню | Исполнитель, название, жанр, смешанная кириллица/латиница, очистка поиска |
| Отобрать песни | Все существующие категории × жанры × языки: точный набор ID и пустое состояние |
| Снять фильтры | Повторный выбор категории, обе кнопки сброса, подписи меню |
| Упорядочить список | Все четыре сортировки: полный порядок ID и группы |
| Выбрать песню | Клик без запуска, заголовок, метки, тексты всех песен |
| Выбрать случайно | Кнопка и R, пустой список, один результат, отсутствие повтора и автозапуска |
| Управлять клавиатурой | /, стрелки, Enter в поиске и списке, Space, F, Y, R, 0, Escape; ввод в поиске не запускает команды |
| Петь | Запуск кнопкой, Enter и двойным кликом; URL нужного видео; пауза кнопкой/Space/кликом по строке; продолжение, перемотка и полная остановка |
| Сменить версию | Полный цикл версий каждой песни без запуска; запрещённая версия до и во время воспроизведения, возврат к рабочей версии |
| Открыть YouTube | Текущий ID, новая вкладка с noopener, запрет повторного автоматического открытия заблокированной версии |
| Читать слова | Точные строки куплета/припева всех песен, отсутствие текста, оверлей, закрытие кнопкой и Escape |
| Настроить размер текста | Увеличение, уменьшение, обе границы, восстановление после перезагрузки |
| Выбрать тему | Все семь тем, сохранение, мышь и клавиатура, закрытие меню и возврат фокуса |
| Вернуться на сайт | Последняя песня без автозапуска, сохранённые настройки, удалённый ID и повреждённые значения |
| Запретить хранилище | Страница, выбор песни, масштаб и темы работают при SecurityError localStorage |
| Открыть без сети | После установки service worker: повторная загрузка, каталог, поиск, текст |
| Использовать телефон | Последовательность поиск → выбор → запуск → текст → закрытие → стоп при 390px; геометрия на ширинах от 320px |
| Использовать меню и подсказки | Мышь, клавиатура, закрытие, положение в окне, темы, отсутствие пересечений |

`ui.test.js` проверяет интерфейс и регрессии вёрстки. `scenarios.js` добавляет
изолированный контекст браузера, перебор фильтров и пользовательские потоки.
Любая проваленная проверка или ошибка JavaScript завершает `npm test` с кодом 1.

## Границы покрытия

Это покрытие перечисленных сценариев в Chromium, а не метрика 100% строк/ветвей.
В дополнительных сценариях внешние запросы заменены пустыми ответами, а команды
плееру проверяются через локальный транспорт iframe. Это проверяет действия
приложения, но не подтверждает звук, доступность ролика, рекламу и работу YouTube.
Для проверки текущих ограничений видео используйте `npm run check-embeds`
при запущенном сервере и проверяйте фактическое воспроизведение вручную.

Офлайн-проверка относится к уже посещённому сайту; видео и внешние шрифты
не становятся доступными без сети. Firefox, Safari, установка PWA, экранные
дикторы и реальные мобильные устройства этим прогоном не проверяются.

`npm run screenshots` — отдельный вспомогательный скрипт снимков при работающем
`npm start`. Он не сравнивает изображения с эталоном и не заменяет тесты.
