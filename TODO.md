## 2. Растянуть плеер по ширине карточки

Реализовано: `.video-shell` занимает всю внутреннюю ширину карточки с пропорциями `16:9`, без ограничения через высоту окна. Начальное состояние, iframe и сообщение YouTube используют одну рамку. На узких экранах длинное сообщение прокручивается внутри рамки, включая обе кнопки.

- [x] Сделать видеоблок шириной `100%` внутренней области карточки.
- [x] Сохранить пропорции `16:9`, без растягивания и обрезания изображения.
- [x] Убрать ограничение ширины через высоту окна. Увеличение высоты плеера согласовано: текст песни может находиться ниже, поскольку предназначен для ознакомления.
- [x] Согласовать размеры обычного плеера, начального состояния и сообщения о запрете встраивания YouTube.
- [x] Проверить доступность кнопок и текста песни на небольших ноутбуках и телефонах, при необходимости через прокрутку.

Критерий готовности: видеоблок занимает всю ширину карточки без боковых полос, добавленных вёрсткой сайта. Полосы внутри самого ролика зависят от исходного видео.
